# Mentor-Journal

Neuester Eintrag zuoberst. Wird am Ende jedes Gesprächs fortgeschrieben,
still und ohne Vorlesen. Persönlich — wird nie zitiert ausser gegenüber AA.

Format:

```
## <Datum> — <Thema in drei Wörtern>
Anlass: <ein Satz>
Kern: <was wirklich dahinterlag>
Vereinbart: <die eine Sache, bis wann — oder «nichts»>
Offen: <was ungeklärt blieb>
```

---

_Noch keine Gespräche._
